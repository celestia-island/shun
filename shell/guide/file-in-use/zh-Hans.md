# 有个文件还开着

安装器要替换的文件正被别的程序占着。通常是产品自己——还在跑，或者刚关掉还没退干净。

- 把程序关掉（托盘里也看一眼），等几秒，再装一次。
- 还不行就重启电脑，重启一定能放开这个文件。
- 任务管理器里搜一下产品名，还有残留进程就先结束掉。

安装日志里会写是哪个文件没换掉，翻到那一行就知道该关什么。

还有一种情况：旧版本的开机自启项还在，程序表面上关了，后台其实又起来了。到任务管理器 → 启动里把它关掉再装，装完再打开。日志里那个路径可以复制到资源监视器里搜，能看出是哪个进程占着。还有一种常见情况：安装目录开在资源管理器窗口里，缩略图预览会把文件锁住，切到别的文件夹或直接关掉那个窗口再装。装完之前别去点开安装目录看，预览会再锁一次。
