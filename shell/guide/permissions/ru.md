# Нет прав на запись

Установщик попробовал записать файлы в эту папку, а Windows не разрешил. Обычно папка принадлежит администратору, лежит в Program Files или это корень диска.

- Выберите папку, которая ваша: та, что установщик предлагает по умолчанию, безопасна.
- Либо закройте установщик, нажмите на него правой кнопкой и выберите **Запуск от имени администратора**.
- В Linux ставьте в домашнюю папку, а не в системную — или запускайте с sudo.

Предлагаемая по умолчанию папка лежит в вашем профиле, поэтому администратор там не нужен. Папка на флешке или сетевом диске тоже может быть недоступна — сначала попробуйте локальный диск.

[Справка Windows: параметры контроля учётных записей](https://learn.microsoft.com/ru-ru/windows/security/application-security/application-control/user-account-control/settings-and-configuration)
