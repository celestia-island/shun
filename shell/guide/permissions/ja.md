# 書き込む権限がありません

インストーラーがこのフォルダーに書き込もうとして、Windows に断られました。管理者のフォルダー、Program Files の下、ドライブのルートのどれかです。

- 自分が使えるフォルダーを選んでください。インストーラーが最初に出す場所なら安全です。
- インストーラーを閉じて、右クリックから**管理者として実行**を選ぶ方法もあります。
- Linux ではホームフォルダーに入れてください。システムのフォルダーに置くなら sudo で実行します。
- C:\ の直下や Program Files には入れないでください。そこは必ず管理者権限が要ります。

インストーラーが最初に出す場所はユーザーフォルダーの下なので、管理者権限は要りません。USB メモリやネットワークドライブのフォルダーでも断られることがあるので、まずは内蔵ディスクに変えてみてください。

[Windows の参考: ユーザー アカウント制御のしくみ](https://learn.microsoft.com/ja-jp/windows/security/application-security/application-control/user-account-control/how-it-works)

---

解決しないときは、選んだフォルダーとログの 1 行を開発者に送ってください。
