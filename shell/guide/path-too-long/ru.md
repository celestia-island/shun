# Слишком длинный путь

По умолчанию Windows даёт пути 260 символов. Папка установки вместе с именами файлов вышла за эту границу, и Windows отказался их создавать.

- Выберите папку покороче, например C:\App.
- Держите её ближе к корню диска — каждая лишняя папка съедает символы.

Достаточно перенести папку установки в короткий путь вроде C:\X — установщик запомнит последний выбор. Считаются и имена папок, и имена файлов.

[Майкрософт об ограничении: максимальная длина пути](https://learn.microsoft.com/ru-ru/windows/win32/fileio/maximum-file-path-limitation)
