# パスが長すぎます

Windows は既定でパスに 260 文字までしか許しません。インストール先のフォルダーとファイル名がそれを超えたため、Windows が作成を拒否しました。

- もっと短いフォルダーを選んでください（例: C:\App）。
- ドライブのルートに近づけてください。フォルダーが増えるほど文字を消費します。
- 「ダウンロード/新しいフォルダー/新しいフォルダー」のような深い入れ子は避けてください。

ログには実際に試した完全なパスが出るので、その文字数を数えれば足りているか分かります。

たとえば C:\Users\名前\AppData\Local\Temp\ダウンロード\新しいフォルダー\製品名\バージョン\bin\あるファイル.dll のように重なると、すぐ 260 を超えます。Windows 10 1607 以降は OS 側が長いパスに対応していますが、追いついていないプログラムも多いです。

[Microsoft の解説: 最大パス長](https://learn.microsoft.com/ja-jp/windows/win32/fileio/maximum-file-path-limitation)

---

解決しないときは、選んだフォルダーを開発者に送ってください。
