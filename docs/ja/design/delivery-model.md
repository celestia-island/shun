# 配布モデル

shun はデスクトップソフトウェア公開の「配送」側を担います。3 つの直交する
部品に分かれます。

## Payload

アプリケーションディレクトリを、SHA-256 マニフェスト（`shun-manifest.json`）
付きの zstd 圧縮 tar にパックします。アーカイブはインストーラーバイナリに
埋め込む（`include_bytes!`、シングルファイルインストーラー）か、サイドカーと
して携帯できます。展開時はエントリーごとにマニフェストを検証し、進捗イベントを
ストリームします。

## Flow

一度の配布実行は `FlowEvent` の連なりです — `started`、
`progress { phase, step, percent }`、`completed`、`failed` — をシェル UI が
直接描画します。進捗は**多層**です：オンラインインストーラーはダウンロード
（download）と展開（extract）の両フェーズを同時に進めます。インストールフローは
payload を展開し、マニフェストをディスクに書き（アンインストールが消費）、
その後ローカルモードなら登録、ポータブルモードならマーカーを書き込みます。

## Targets

- **install** — NSIS 風の登録（ユーザー単位の ARP エントリー、自己コピーする
  アンインストーラー、スタートメニューショートカット、ディープリンク）に加え、
  レジストリに一切触れないポータブルモード。アンインストールはマニフェストに
  従って全痕跡を除去します。
- **flash** — ブロックデバイスへの書き込みと検証（イメージフラッシュ）。実装は
  evernight フラッシャーと共に提供。trait 界面とデバイス列挙は提供済み。

## WebView2（Windows）

シェル自身も Tauri アプリのため、WebView2 ランタイムはその UI の必須前提です。
配布マニフェストが戦略を選択：システムランタイムを要求するか、Evergreen
オフラインインストーラーを埋め込むか、固定バージョンのランタイムを私的に
携帯するか — 1 部のコピーをシェルとインストール済みアプリで共有し、インストール
とポータブルの両モードにわたって機能します。
