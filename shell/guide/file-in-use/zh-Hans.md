# 有个文件还开着

安装器要替换的文件正被别的程序占着。通常是产品自己——还在跑，或者刚关掉还没退干净。

- 把程序关掉（托盘里也看一眼），等几秒，再装一次。
- 还不行就重启电脑，重启一定能放开这个文件。
- 任务管理器里搜一下产品名，还有残留进程就先结束掉。

安装日志里会写是哪个文件没换掉，翻到那一行就知道该关什么。右下角托盘里经常还留着一个进程，右键退出它再装。

还有一种情况：旧版本的开机自启项还在，程序表面上关了，后台其实又起来了。到任务管理器 → 启动里把它关掉再装，装完再打开。如果占着文件的是杀毒软件（刚扫过这个文件），等半分钟再装也能过去。要是刚装完就启动时报的错，多半是上一轮安装留下的进程还没退干净，重装前多等十秒，实在不行就重启。
