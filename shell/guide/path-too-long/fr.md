# Le chemin est trop long

Par défaut, Windows limite un chemin à 260 caractères. Le dossier d'installation et les noms de fichiers ont dépassé cette limite, donc Windows a refusé de les créer.

- Choisissez un dossier plus court, par exemple C:\App.
- Gardez-le près de la racine du disque : chaque dossier en plus consomme des caractères.

Le journal affiche le chemin complet essayé : vous pouvez compter les caractères vous-même.

[L'explication de Microsoft : longueur maximale d'un chemin](https://learn.microsoft.com/fr-fr/windows/win32/fileio/maximum-file-path-limitation)
