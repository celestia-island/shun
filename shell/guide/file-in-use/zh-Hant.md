# 有個檔案還開著

安裝程式要替換的檔案正被別的程式佔用。通常是產品自己——還在跑，或者剛關掉還沒完全結束。

- 把程式關掉（系統匣也看一眼），等幾秒，再裝一次。
- 還不行就重新開機，重新開機一定能放開這個檔案。
- 工作管理員裡搜一下產品名稱，還有殘留行程就先結束掉。

安裝日誌裡會寫是哪個檔案沒換掉，翻到那一行就知道該關什麼。

還有一種情況：舊版本的開機自啟項還在，程式表面上關了，背景其實又起來了。到工作管理員 → 啟動裡把它關掉再裝，裝完再打開。日誌裡那個路徑可以複製到資源監視器裡搜，能看出是哪個行程佔著。還有一種常見情況：安裝目錄開在檔案總管視窗裡，縮圖預覽會把檔案鎖住，切到別的資料夾或直接關掉那個視窗再裝。裝完之前別去點開安裝資料夾看，預覽會再鎖一次。
