# The download didn't finish

Part of the install comes over the network, and that download never reached the server: no connection, a proxy blocking it, or a mirror that was down.

- Check you're online, then retry. A VPN or a company proxy can block the download.
- Behind a proxy? Set it in your system settings first, then retry.

Company networks sometimes need IT to allow the download host, and a phone hotspot tells you in a minute whether the network is the problem. The log's download URL shows which server was unreachable.

[Windows reference: fix Wi-Fi connection issues](https://support.microsoft.com/en-us/windows/experience/connectivity-networking/fix-wi-fi-connection-issues-in-windows)
