# 有個檔案還開著

安裝程式要替換的檔案正被別的程式佔用。通常是產品自己——還在跑，或者剛關掉還沒完全結束。

- 把程式關掉（系統匣也看一眼），等幾秒，再裝一次。
- 還不行就重新開機，重新開機一定能放開這個檔案。
- 工作管理員裡搜一下產品名稱，還有殘留行程就先結束掉。

安裝日誌裡會寫是哪個檔案沒換掉，翻到那一行就知道該關什麼。右下角系統匣裡經常還留著一個行程，按右鍵結束它再裝。

還有一種情況：舊版本的开機自啟項還在，程式表面上關了，背景其實又起來了。到工作管理員 → 啟動裡把它關掉再裝，裝完再打開。如果佔著檔案的是防毒軟體（剛掃過這個檔案），等半分鐘再裝也能過去。要是剛裝完就啟動時報的錯，多半是上一輪安裝留下的行程還沒退乾淨，多等一會兒再試。

[Windows 參考：共用衝突是怎麼回事](https://learn.microsoft.com/zh-tw/troubleshoot/windows-server/performance/copying-exe-files-sharing-violation-error-folder-in-use)
