# 程式不見了

裝是裝完了，但安裝資料夾裡少了程式的主檔案。十之八九是防毒軟體把它拿走了。

- 先把安裝資料夾加入防毒軟體的白名單，再裝一次。
- 如果還是消失，把防毒軟體的名稱發給開發者——可能需要一份帶簽章的版本。
- 看看安裝資料夾是不是被「受控資料夾存取」之類功能鎖住，關掉再裝。

防毒軟體通常把檔案放進「隔離區」，從那裡還原並選信任，比重新安裝更快。如果每次裝完都少檔案，把安裝資料夾整個加進白名單最省事。

先打開安裝資料夾自己看一眼：主程式一般是 .exe，如果只剩幾個空資料夾，那就是真的被拿走了。順便看工作管理員裡有沒有殘留行程，以及防毒軟體的隔離區裡有沒有同名檔案——在隔離區裡還原並選擇信任，通常幾秒就好。如果每次裝完都少檔案，把整個安裝資料夾加進排除項再裝一遍；裝完先別關安裝程式，直接啟動一次，能起來就說明這次留住了。公司電腦上還可能是安全策略直接刪掉未知程式，可以問一下 IT 有沒有這類規則。要是隔離區裡也沒有記錄，那檔案可能根本沒寫進去，重裝時留意日誌有沒有報錯——安裝程式會寫清楚哪一步沒寫成，把那幾行一起發給開發者最省事。

---

把安裝資料夾和日誌裡那行發給開發者，他們能核對打包。
