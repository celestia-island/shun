# Un fichier est encore utilisé

L'installateur doit remplacer un fichier que quelque chose garde ouvert. Le plus souvent c'est l'application elle-même — encore lancée, ou tout juste fermée.

- Quittez l'application (regardez aussi la zone de notification), attendez quelques secondes, puis relancez l'installateur.
- Sinon, redémarrez l'ordinateur : un redémarrage libère le fichier à coup sûr.

Le journal d'installation nomme le fichier qu'il n'a pas pu remplacer : cette ligne dit quoi fermer. Un processus traîne souvent dans la zone de notification.

[Référence Windows : régler un conflit d'accès](https://learn.microsoft.com/fr-fr/troubleshoot/windows-server/performance/copying-exe-files-sharing-violation-error-folder-in-use)
