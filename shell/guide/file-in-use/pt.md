# Um ficheiro ainda está em uso

O instalador tem de substituir um ficheiro que outro programa mantém aberto. Normalmente é a própria aplicação — ainda a correr ou acabada de fechar.

- Feche a aplicação (veja também a área de notificação), espere alguns segundos e instale outra vez.
- Se não resolver, reinicie o computador: um reinício liberta o ficheiro de certeza.

O registo de instalação indica o ficheiro que não foi possível substituir: essa linha diz o que fechar. Muitas vezes fica um processo na área de notificação.

[Referência do Windows: resolver uma violação de partilha](https://learn.microsoft.com/pt-pt/troubleshoot/windows-server/performance/copying-exe-files-sharing-violation-error-folder-in-use)
