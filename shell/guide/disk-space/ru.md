# На диске мало места

Пока установщик писал файлы, на диске кончилось место. Windows останавливается сразу, как только целевой диск заполнен — даже в середине копирования.

- Освободите немного места или выберите в установщике другой диск.
- Windows: Параметры → Система → Память. macOS: Системные настройки → Основные → Хранилище. Linux: дисковое приложение вашего дистрибутива.

Оставьте хотя бы гигабайт свободным: при распаковке рядом лежит вторая копия файлов, да и кэш загрузки занимает место.

[Справка Windows: как освободить место на диске](https://support.microsoft.com/ru-ru/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)
