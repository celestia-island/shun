# Der Download ist nicht durchgelaufen

Ein Teil der Installation wird geladen, und dieser Download hat den Server nie erreicht: keine Verbindung, ein blockierender Proxy oder ein Spiegel, der gerade weg war.

- Prüfen Sie die Verbindung und versuchen Sie es erneut. Ein VPN oder der Firmen-Proxy blockiert solche Downloads oft.
- Hinter einem Proxy? Tragen Sie ihn zuerst in den Systemeinstellungen ein, dann erneut versuchen.

In Firmennetzen muss die IT manchmal den Download-Host freigeben, und ein Handy-Hotspot zeigt in einer Minute, ob das Netz schuld ist. Die URL im Protokoll verrät, welcher Server nicht antwortete.

[Windows-Hilfe: WLAN-Verbindungsprobleme beheben](https://support.microsoft.com/de-de/windows/experience/connectivity-networking/fix-wi-fi-connection-issues-in-windows)

---

Immer noch nicht? Schicken Sie dem Entwickler die Download-URL aus dem Protokoll.
