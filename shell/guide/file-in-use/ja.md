# ファイルが使用中です

インストーラーが置き換えたいファイルを、別のプログラムが開いたままにしています。たいていはアプリ自身で、まだ動いているか、閉じた直後です。

- アプリを終了してください（タスクトレイも確認）。数秒待ってから、もう一度インストールします。
- それでもだめならパソコンを再起動してください。再起動すればファイルは必ず離れます。
- タスク マネージャーで製品名を検索し、残っているプロセスがあれば終了してください。

インストールログに、置き換えられなかったファイル名が出ます。その行を見れば何を閉じればよいか分かります。

もう一つよくあるのが、旧バージョンの自動起動が残っていて、閉じたはずのアプリが裏で起動し直しているケースです。タスク マネージャーのスタートアップで切ってから入れて、終わったら戻してください。ログのパスをリソース モニターで検索すると、どのプロセスが掴んでいるか分かります。

[Windows の参考: 共有違反の調べ方](https://learn.microsoft.com/ja-jp/troubleshoot/windows-server/performance/copying-exe-files-sharing-violation-error-folder-in-use)

---

解決しないときは、ログに出ているファイル名を開発者に送ってください。
