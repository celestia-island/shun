# Быстрый старт

shun состоит из двух половин: **сборка** (упаковка payload, разрешение
манифеста доставки) и **исполнение** (оболочка, ведущая поток).

## Попробуйте демо

```bash
cargo run --example demo_flash                        # перечисление флеш-устройств
cargo run --example demo_install                      # генерирует ShunDemo.shun + локальная установка
cargo run --example demo_install -- --portable        # портативная установка (без реестра)
cargo run --example demo_install -- --uninstall       # удаление (все следы убираются)
```

`demo_install` создаёт установочный пакет `ShunDemo.shun`, распаковывает его
с потоковым прогрессом и — в локальном режиме — выполняет прямую Windows
регистрацию: запись ARP уровня пользователя (Параметры → Приложения), ярлык
в меню «Пуск» и самокопирующий деинсталлятор. Портативный режим пишет только
маркер `.shun-portable` и не касается реестра.

## Запуск демо-оболочки

```bash
pnpm --dir shell/web install
cargo run -p shun_demo_shell
```

Оболочка встраивает демо-payload во время сборки (паттерн однофайлового
установщика) и отображает режимы доставки, объявленные в
`shell/Cargo.toml` → `[package.metadata.shun]`.
