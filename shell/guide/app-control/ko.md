# 실행이 Windows 앱 제어에 의해 차단되었습니다

설치는 끝났습니다. 실패한 것은 실행 단계로, Windows가 실행 파일을 시작하기 전에 막았고 앱은 **os error 4551**을 보고했습니다. Windows가 **0x11C7**이라고 부르는 차단과 같은 것입니다. **0x11C7**은 16진수 상태 코드, **4551**은 그 10진수 표기입니다. 파일은 모두 디스크에 있고 빠진 것은 없습니다.

Windows는 인식할 수 있는 코드, 또는 신뢰할 수 있는 게시자가 서명한 코드만 실행합니다. 개인용 Windows 11에서는 이 관문이 '스마트 앱 컨트롤'이고, Windows 10이나 조직에서 관리하는 PC에서는 '앱 제어(WDAC)' 또는 AppLocker가 그 역할을 합니다. 판단 방식은 단순합니다. 먼저 클라우드 평판으로 안전한지 판단하고, 판단할 수 없으면 유효한 서명이 있는지 확인하며, 둘 다 없으면 '신뢰할 수 없음'으로 차단합니다.

![스마트 앱 컨트롤 스위치의 위치](guide/app-control-1.png)

## 스위치 위치

- **①** **설정 → 개인 정보 및 보안 → Windows 보안**을 열고 **Windows 보안 열기**를 클릭합니다.
- **②** **앱 및 브라우저 컨트롤**로 들어가 **스마트 앱 컨트롤**을 선택합니다.
- **③** 표시된 상태를 확인합니다. **켜기**는 서명되지 않았거나 인식되지 않는 앱을 차단하고, **평가**는 관찰만 하며 차단하지 않고, **끄기**는 아무것도 제한하지 않습니다.

![스마트 앱 컨트롤의 세 가지 상태](guide/app-control-2.png)

## 본인 PC에서의 해결

상태가 **켜기**라면 이번 차단은 스마트 앱 컨트롤이 한 것입니다. 같은 화면에서 **스마트 앱 컨트롤 → 설정**을 열고 **끄기**로 바꾸세요. 개인 사용자에게는 이것이 유일한 방법입니다.

다만 Microsoft는 이를 단방향 조작이라고 설명합니다. 예전에는 되살리려면 Windows 초기화나 재설치가 필요했지만, 최근 업데이트에서는 Windows 보안 앱 안에서 다시 켤 수 있습니다. 실제 화면이 기준입니다.

상태가 **평가** 또는 **끄기**라면 스마트 앱 컨트롤은 아무것도 막지 않고 있습니다. 다른 정책이 적용 중이므로 아래 관리자 절차를 따라 주세요.

![앞으로 나아가는 세 가지 길](guide/app-control-3.png)

## 설정을 관리자가 쥐고 있는 경우

회사나 학교 PC에서는 스위치가 회색으로 표시되거나 아예 없습니다. Windows 10에는 스마트 앱 컨트롤 자체가 없습니다. 이때의 차단은 정책에서 비롯되므로, 오류 코드와 실행 파일의 전체 경로, 아래 이벤트 정보를 관리자에게 보내세요. 관리자는 게시자 인증서를 정책에 추가하거나 이 파일 하나만 허용하는 규칙을 만들 수 있습니다.

## 그 밖의 선택

- **서명된 빌드를 요청하세요.** 앱 제어를 켜 둔 채로 해결하는 유일한 방법입니다. Microsoft는 유효한 인증서로 서명할 것을 개발자에게 권고하며, 서명되지 않은 빌드는 어떻게 설치해도 '신뢰할 수 없음'으로 남습니다. 서명은 설치 파일과 실제로 차단된 실행 파일을 모두 포함해야 합니다.
- **'차단 해제'는 해결책이 아닙니다.** 마우스 오른쪽 단추 → 속성 → 차단 해제는 '인터넷에서 받음' 표시만 지울 뿐, 앱 제어 정책을 덮어쓰지 않습니다.
- **앱별 허용 목록은 없습니다.** Microsoft는 스마트 앱 컨트롤을 특정 앱 하나만 예외로 둘 수 없다고 밝혔습니다. 설정에서 찾아도 나오지 않습니다.

## 증거 확인

이벤트 뷰어 → 응용 프로그램 및 서비스 로그 → Microsoft → Windows → **CodeIntegrity → Operational**:**3077**은 적용 중인 정책에 의한 차단, **3076**은 그 감사 모드 버전입니다. **3033**은 해지·만료된 서명을 가리키는 경우가 많지만 앱 제어 정책이 없어도 기록될 수 있어, 그것만으로 원인이라 단정할 수 없습니다. 스크립트와 MSI 차단은 **AppLocker → MSI and Script**에 기록됩니다. 3077도 3076도 없다면 차단이 다른 곳에서 일어났거나 로그에 남지 않은 것입니다.
