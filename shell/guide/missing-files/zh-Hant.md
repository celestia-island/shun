# 程式不見了

裝是裝完了，但安裝資料夾裡少了程式的主檔案。十之八九是防毒軟體把它拿走了。

- 先把安裝資料夾加入防毒軟體的白名單，再裝一次。
- 如果還是消失，把防毒軟體的名稱發給開發者——可能需要一份帶簽章的版本。
- 看看安裝資料夾是不是被「受控資料夾存取」之類功能鎖住，關掉再裝。

防毒軟體通常把檔案放進「隔離區」，從那裡還原並選信任，比重新安裝更快。

先打開安裝資料夾看一眼：主程式一般是 .exe，如果只剩幾個空資料夾，那就是真的被拿走了。資源回收筒裡也搜一下產品名稱，有時檔案只是被刪掉、沒進隔離區。公司電腦上還可能是安全策略直接刪掉未知程式，問一下 IT 有沒有這類規則。核對的笨辦法很管用：健康的安裝資料夾裡應該有主程式、幾個 dll 和 resources 之類的資料夾；整個目錄幾乎是空的代表解壓就沒成，只有主程式不在就基本上是被防護軟體拿走了。如果防毒軟體是單位統一裝的、設定根本改不了，就把目錄截圖和日誌一起發給 IT，請他們加一條排除規則。另外，把安裝包複製到本機磁碟再雙擊，別在壓縮檔裡直接執行——從壓縮檔執行時有時解壓到暫存目錄會少檔案。

---

把安裝資料夾和日誌裡那行發給開發者，他們能核對打包。
