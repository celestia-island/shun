- 不收取任何许可费用。

## 2. 便携模式说明

选择便携模式时：

1. 程序仅在目标目录写入 `bin/`、`data/` 等负载文件；
2. 根目录会生成 `.shun-portable` 标记文件；
3. **不写入任何注册表项**、不创建开始菜单快捷方式；
4. 卸载即删除整个目录，不留痕迹。

## 3. 本机模式说明

选择安装到本机时：

- 程序将登记到系统「应用」列表（`HKCU\...\Uninstall`）；
- 开始菜单会创建指向入口点的快捷方式；
- 卸载器支持从系统设置或本界面发起。
