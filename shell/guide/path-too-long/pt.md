# O caminho é longo demais

O Windows só dá 260 caracteres a um caminho, por predefinição. A sua pasta de instalação e os nomes dos ficheiros passaram disso, por isso o Windows recusou criá-los.

- Escolha uma pasta mais curta, por exemplo C:\App.
- Deixe-a perto da raiz da unidade: cada pasta extra gasta caracteres.

O registo mostra o caminho completo que foi tentado: pode contar os caracteres.

[A explicação da Microsoft: comprimento máximo do caminho](https://learn.microsoft.com/pt-pt/windows/win32/fileio/maximum-file-path-limitation)
