# 路径太长了

Windows 默认只给路径 260 个字符。安装文件夹加上里面的文件名超过了这个数，Windows 就不肯建。

- 换一个短一点的文件夹，比如 C:\App。
- 尽量放在盘符根目录附近，每多一层文件夹都在吃字符。
- 别把安装目录套在「下载/新建文件夹/新建文件夹」这种层层嵌套的路径里。

把安装目录挪到 C:\X 这种短路径就够了，安装器会记住上次的选择。文件夹名和文件名都算长度，中文名也照样占字。

算一笔账：C:\Users\你的名字\AppData\Local\Temp\下载\新建文件夹\产品名\版本\bin\某个文件.dll，这样一层层叠下去，很容易就过 260。日志里会打印完整路径，复制出来数一下最准。Windows 10 1607 以后系统本身支持更长路径，但很多程序还没跟上，所以最省事的做法还是把安装目录挪短。短路径也能省掉以后的一堆麻烦。

[微软的说明：路径长度上限](https://learn.microsoft.com/zh-cn/windows/win32/fileio/maximum-file-path-limitation)
