# 磁盘空间不够了

写文件的过程中盘满了。目标盘一满，Windows 立刻就停下，哪怕复制到一半。

- 清点空间，或者在安装器里换一个盘。
- Windows：设置 → 系统 → 存储。macOS：系统设置 → 通用 → 储存空间。Linux：发行版自带的磁盘工具。
- 别选快满的盘：剩几百兆的时候，安装一定会在中途停下。

装之前留出 1 GB 以上比较稳，解压时还要在旁边占一份临时空间。临时文件和下载缓存也占地方，清一遍往往就够了。

清理顺序一般是：先清下载目录和浏览器缓存，再看「磁盘清理」里的系统临时文件，最后才动照片和视频。解压后的大小通常是压缩包的两到三倍，选盘时按这个估。装完也留一点余量——程序运行时还要写日志和缓存。空间不够时 Windows 一般不会直接说「磁盘已满」，而是写一半就失败，所以别只盯着错误码。

[Windows 参考：怎么释放磁盘空间](https://support.microsoft.com/zh-cn/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)
