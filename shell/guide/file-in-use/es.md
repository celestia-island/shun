# Un archivo sigue en uso

El instalador tiene que reemplazar un archivo que otro programa mantiene abierto. Casi siempre es la propia aplicación: sigue abierta o acaba de cerrarse.

- Cierra la aplicación (mira también la bandeja), espera unos segundos y vuelve a instalar.
- Si no funciona, reinicia el equipo: un reinicio libera el archivo seguro.

El registro de instalación indica el archivo que no pudo reemplazar: esa línea te dice qué cerrar. Muchas veces queda un proceso en el área de notificación.

[Referencia de Windows: resolver un conflicto de acceso](https://learn.microsoft.com/es-es/troubleshoot/windows-server/performance/copying-exe-files-sharing-violation-error-folder-in-use)
