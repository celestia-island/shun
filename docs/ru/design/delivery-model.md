# Модель доставки

shun отвечает за «доставку» при выпуске настольного ПО. Три ортогональные
части:

## Payload

Каталог приложения, упакованный в zstd-сжатый tar с манифестом SHA-256
(`shun-manifest.json`). Архив встраивается в бинарник установщика
(`include_bytes!`, паттерн однофайлового установщика) или поставляется
рядом. Распаковка сверяет каждый элемент с манифестом и транслирует события
прогресса.

## Flow

Один запуск доставки — это последовательность `FlowEvent` — `started`,
`progress { phase, step, percent }`, `completed`, `failed` — которую UI
оболочки рендерит напрямую. Прогресс **многослойный**: онлайн-установщик
одновременно продвигает фазы скачивания (download) и распаковки (extract).
Поток установки распаковывает payload, пишет манифест на диск (его читает
деинсталляция), затем либо регистрирует установку (локальный режим), либо
пишет портативный маркер (портативный режим).

## Targets

- **install** — прямая регистрация по платформам: в Windows — запись ARP уровня пользователя, само-копирующийся деинсталлятор, ярлыки в меню «Пуск» и на рабочем столе (с AUMID) и опциональные команды контекстного меню Проводника; в Linux — пользовательский лаунчер `.desktop` с действиями рабочего стола (включая удаление); в macOS — достройка бандла `.app` плюс регистрация в Launch Services. Портативный режим ни на одной платформе не трогает системное состояние. Удаление стирает все следы по манифесту.
- **flash** — запись на блочные устройства с проверкой после записи (прошивка
  образов). Бэкенд приходит вместе с evernight; поверхность trait и
  перечисление устройств доступны уже сейчас.

## WebView2 (Windows)

Оболочка сама является приложением Tauri, поэтому рантайм WebView2 — жёсткое
условие её собственного UI. Манифест доставки выбирает стратегию: требовать
системный рантайм, встроить Evergreen-установщик или приватно переносит
рантайм фиксированной версии — одна копия делится оболочкой и установленным
приложением в режимах install и portable.
