# 下载没完成

安装的一部分要从网上下载，这次没能连上服务器——没有网络、代理挡住了，或者镜像正好在维护。

- 先确认能上网，再点一次重试。VPN 和公司代理经常挡这个下载。
- 走代理的话，先在系统设置里填好代理，再重试。
- 代理设置在「设置 → 网络和 Internet → 代理」里，填好再重试。

公司网络有时要 IT 放行安装包用的域名；换个网络或手机热点，一分钟就能判断是不是网络的问题。重试之前先看一眼日志里的下载地址，能看出是哪个服务器没通。

如果日志里的下载地址指向内网镜像，先确认那台机器还开着；换成公网镜像往往立刻就能装。临时关掉 VPN 再试一次也值得——很多「连不上」其实是 VPN 把流量带到了走不通的地方。公司电脑也可能是防火墙把安装器本身拦了。
