# 배포 모델

shun은 데스크톱 소프트웨어 배포의 "전달" 절반을 담당합니다. 세 개의 직교하는
부품으로 나뉩니다.

## Payload

애플리케이션 디렉터리를 SHA-256 매니페스트(`shun-manifest.json`)가 포함된
zstd 압축 tar로 패키징합니다. 아카이브는 설치 바이너리에 내장되거나
(`include_bytes!`, 단일 파일 설치 패턴) 사이드카로 전달될 수 있습니다. 압축
해제 시 매니페스트대로 각 항목을 검증하며 진행 이벤트를 스트림합니다.

## Flow

한 번의 배포 실행은 `FlowEvent`의 연속입니다 — `started`,
`progress { phase, step, percent }`, `completed`, `failed` — 셸 UI가 직접
렌더링합니다. 진행률은 **다층**입니다: 온라인 설치 관리자는 다운로드(download)와
압축 해제(extract) 페이즈를 동시에 진행합니다. 설치 플로우는 payload를 풀고,
디스크에 매니페스트를 기록(제거 프로그램이 소비)한 뒤, 로컬 모드면 등록을,
휴대용 모드면 마커를 기록합니다.

## Targets

- **install** —— 플랫폼별 직접 등록: Windows에서는 사용자 단위 ARP 항목, 자가 복사 제거 프로그램, 시작 메뉴/바탕 화면 바로 가기(AUMID 포함), 선택적 탐색기 상황에 맞는 메뉴 동사. Linux에서는 데스크톱 액션(제거 포함)을 갖춘 사용자 단위 `.desktop` 런처. macOS에서는 `.app` 번들 완성과 Launch Services 등록. 휴대용 모드는 어떤 플랫폼에서도 시스템 상태를 건드리지 않는다. 제거는 매니페스트에 따라 모든 흔적을 지운다.
- **flash** — 블록 디바이스 쓰기와 사후 검증(이미지 굽기). 백엔드는 evernight
  플래셔와 함께 제공되며, trait 인터페이스와 장치 열거는 오늘 제공됩니다.

## WebView2 (Windows)

셸 자체도 Tauri 앱이므로 WebView2 런타임은 자체 UI의 필수 전제입니다. 배포
매니페스트가 전략을 선택합니다: 시스템 런타임 요구, Evergreen 오프라인
설치 관리자 내장, 또는 고정 버전 런타임을 사적으로 휴대 — 한 부의 복사본을
셸과 설치된 앱이 공유하며 설치와 휴대 모드 전반에 걸쳐 작동합니다.
