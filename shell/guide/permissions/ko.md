# 쓸 수 있는 권한이 없습니다

설치 관리자가 이 폴더에 파일을 쓰려는데 Windows가 거절했습니다. 관리자 폴더, Program Files 아래, 드라이브 루트 중 하나입니다.

- 내가 쓸 수 있는 폴더를 고르세요. 설치 관리자가 처음 보여 주는 위치가 안전합니다.
- 설치 관리자를 닫고 마우스 오른쪽 단추로 **관리자 권한으로 실행**을 골라도 됩니다.
- Linux에서는 홈 폴더에 설치하세요. 시스템 폴더에 두려면 sudo로 실행합니다.
- C:\ 바로 아래나 Program Files에는 설치하지 마세요. 그곳은 항상 관리자 권한이 필요합니다.

설치 관리자가 처음 보여 주는 위치는 사용자 폴더 아래라 관리자 권한이 필요 없습니다. USB나 네트워크 드라이브의 폴더도 거절될 수 있으니 먼저 내장 디스크로 바꿔 보세요.

[Windows 참고: 사용자 계정 컨트롤 설정](https://learn.microsoft.com/ko-kr/windows/security/application-security/application-control/user-account-control/settings-and-configuration)
