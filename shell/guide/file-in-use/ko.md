# 파일이 아직 사용 중입니다

설치 관리자가 바꿔야 할 파일을 다른 프로그램이 붙잡고 있습니다. 보통은 앱 자신으로, 아직 실행 중이거나 막 닫힌 상태입니다.

- 앱을 종료하고(트레이도 확인) 몇 초 기다렸다가 다시 설치하세요.
- 그래도 안 되면 컴퓨터를 다시 시작하세요. 재부팅하면 파일이 확실히 풀립니다.
- 작업 관리자에서 제품 이름을 검색해 남은 프로세스가 있으면 끝내세요.

설치 로그에 바꾸지 못한 파일 이름이 나옵니다. 그 줄을 보면 무엇을 닫아야 하는지 알 수 있습니다.

흔한 경우가 하나 더 있습니다. 예전 버전의 시작 프로그램이 남아 있어서 닫은 줄 알았던 앱이 뒤에서 다시 뜨는 것입니다. 작업 관리자의 시작 프로그램에서 끄고 설치한 뒤 다시 켜면 됩니다. 로그의 경로를 리소스 모니터에서 검색하면 어떤 프로세스가 잡고 있는지 보입니다.

[Windows 참고: 공유 위반 해결하기](https://learn.microsoft.com/ko-kr/troubleshoot/windows-server/performance/copying-exe-files-sharing-violation-error-folder-in-use)
