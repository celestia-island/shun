# ダウンロードが終わりませんでした

インストールの一部はネットワークから取得します。そのダウンロードがサーバーに届きませんでした。接続がない、プロキシに止められた、ミラーが落ちていた、のいずれかです。

- インターネットにつながることを確かめて、もう一度試してください。VPN や社内プロキシが止めていることがよくあります。
- プロキシを使っている場合は、先にシステム設定でプロキシを入れてから再試行します。
- プロキシは「設定 → ネットワークとインターネット → プロキシ」で設定してから再試行してください。

社内ネットワークでは、ダウンロード先を IT に許可してもらう必要があることがあります。スマホのテザリングに切り替えると、ネットワークの問題かすぐ分かります。

[Windows の参考: Wi-Fi 接続の問題を解決する](https://support.microsoft.com/ja-jp/windows/experience/connectivity-networking/fix-wi-fi-connection-issues-in-windows)

---

解決しないときは、ログのダウンロード URL を開発者に送ってください。
