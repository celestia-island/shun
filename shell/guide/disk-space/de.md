# Der Datenträger ist voll

Beim Schreiben lief der Platz aus. Windows hält sofort an, wenn das Ziellaufwerk voll ist — auch mitten im Kopieren.

- Schaffen Sie etwas Platz, oder wählen Sie im Installer ein anderes Laufwerk.
- Windows: Einstellungen → System → Speicher. macOS: Systemeinstellungen → Allgemein → Speicher. Linux: das Datenträger-Werkzeug Ihrer Distribution.

Lassen Sie mindestens ein Gigabyte frei: Beim Entpacken liegt eine zweite Kopie daneben, und der Download-Cache belegt ebenfalls Platz.

[Windows-Hilfe: Speicherplatz freigeben](https://support.microsoft.com/de-de/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)

Immer noch nicht? Schicken Sie dem Entwickler das Laufwerk und den freien Platz.
