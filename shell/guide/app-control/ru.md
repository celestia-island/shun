# Windows не даёт программе запуститься

Установка прошла, файлы на месте. Windows заблокировал только запуск: программа сообщила **os error 4551** — это он же, **0x11C7**.

![Где переключатель](guide/app-control-1.png)

## Выключите его

- **①** Откройте **Параметры → Конфиденциальность и защита → Безопасность Windows**, затем **Открыть Безопасность Windows**.
- **②** Перейдите в **Управление приложениями и браузером**, затем в **Интеллектуальное управление приложениями**.
- **③** Если стоит **Вкл.**, откройте **Интеллектуальное управление приложениями → Параметры** и переключите на **Откл.**

![Три состояния](guide/app-control-2.png)

Обратно этот переключатель включать неудобно: раньше для этого требовался сброс Windows, теперь свежие обновления позволяют сделать это прямо в приложении.

Пункт серый или его вовсе нет? Значит, им управляет администратор или другая политика. Посмотрите **Просмотр событий → Журналы приложений и служб → Microsoft → Windows → CodeIntegrity → Operational**, событие **3077**.

![Три пути](guide/app-control-3.png)
