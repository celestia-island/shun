# 路徑太長了

Windows 預設只給路徑 260 個字元。安裝資料夾加上裡面的檔名超過這個數，Windows 就不肯建立。

- 換一個短一點的資料夾，例如 C:\App。
- 盡量放在磁碟根目錄附近，每多一層資料夾都在吃字元。
- 別把安裝目錄放在「下載/新增資料夾/新增資料夾」這種層層嵌套的路徑裡。

日誌裡會印出它試過的完整路徑，複製出來數一下就知道差多少。

算一筆帳：C:\Users\你的名字\AppData\Local\Temp\下載\新增資料夾\產品名\版本\bin\某個檔案.dll，這樣一層層疊下去，很容易就超過 260。Windows 10 1607 之後系統本身支援更長路徑，但很多程式還沒跟上，所以最省事的做法還是把安裝目錄移短。直接把資料夾拖到 C:\ 下面再重新命名，比一層層退出去快；安裝程式記得上次的選擇，所以移完要重新選一次。

[微軟的說明：路徑長度上限](https://learn.microsoft.com/zh-tw/windows/win32/fileio/maximum-file-path-limitation)
