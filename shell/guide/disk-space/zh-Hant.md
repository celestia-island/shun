# 磁碟空間不夠了

寫檔案的過程中碟滿了。目標碟一滿，Windows 立刻就停下來，哪怕複製到一半。

- 清點空間，或者在安裝程式裡換一個碟。
- Windows：設定 → 系統 → 儲存空間。macOS：系統設定 → 一般 → 儲存空間。Linux：發行版內建的磁碟工具。
- 別選快滿的碟：剩幾百 MB 的時候，安裝一定會在中途停下來。

裝之前留出 1 GB 以上比較穩，解壓時還要在旁邊佔一份暫存空間。暫存檔案和下載快取也佔空間，清一遍往往就夠了。

清理順序一般是：先清下載目錄和瀏覽器快取，再看「磁碟清理」裡的系統暫存檔，最後才動照片和影片。解壓後的大小通常是壓縮檔的兩到三倍，選碟時按這個估。裝完也留一點餘量——程式執行時還要寫日誌和快取。空間不夠時 Windows 通常不會直接說「磁碟已滿」，而是寫一半就失敗。

[Windows 參考：怎麼釋放磁碟空間](https://support.microsoft.com/zh-tw/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)
