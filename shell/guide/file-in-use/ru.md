# Файл ещё занят

Установщику нужно заменить файл, который держит открытым другая программа. Обычно это само приложение — ещё работает или только что закрылось.

- Закройте программу (загляните и в трей), подождите несколько секунд и запустите установщик снова.
- Если не помогло, перезагрузите компьютер — перезагрузка отпускает файл точно.

В журнале установки указано, какой файл не удалось заменить, — по этой строке видно, что именно закрывать.

[Справка Windows: что такое нарушение совместного доступа](https://learn.microsoft.com/ru-ru/troubleshoot/windows-server/performance/copying-exe-files-sharing-violation-error-folder-in-use)

---

Не помогло? Отправьте разработчику имя файла из журнала.
