# 下載沒完成

安裝的一部分要從網路下載，這次沒能連上伺服器——沒有網路、代理擋住了，或者鏡像正好在維護。

- 先確認能上網，再按一次重試。VPN 和公司代理經常擋這個下載。
- 走代理的話，先在系統設定裡填好代理，再重試。
- 代理設定在「設定 → 網路和 Internet → 代理」裡，填好再重試。

公司網路有時要 IT 放行安裝包用的網域；換個網路或手機熱點，一分鐘就能判斷是不是網路的問題。重試之前先看一下日誌裡的下載位址，能看出是哪個伺服器沒通。

如果日誌裡的下載位址指向內網鏡像，先確認那台機器還開著；換成公網鏡像往往立刻就能裝。暫時關掉 VPN 再試一次也值得——很多「連不上」其實是 VPN 把流量帶到了走不通的地方。公司電腦也可能是防火牆把安裝程式本身攔了。
